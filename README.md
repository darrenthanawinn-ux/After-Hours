# AFTER HOURS — The Hallway Bell

A 2D pixel-art mystery-horror adventure. One self-contained file, no installs, no internet needed.

## How to run
1. Unzip the folder.
2. Double-click `index.html` (any modern browser: Chrome, Edge, Firefox, Safari).
3. Press any key at the title screen. Headphones and a dark room recommended.

## Controls
| Key | Action |
|---|---|
| WASD / Arrow keys | Move |
| E / Space / Enter | Interact, advance dialogue |
| F | Flashlight on/off (once you find it) |
| Esc / I / Tab | Menu: items, notes, current objective |
| M | Mute |

## Tips
- Read everything. Notes you find are saved in the menu (NOTES tab).
- Stuck? Open the menu: the bottom line always shows your current objective.
- Some things in the dark don't like to be looked at. Light is your friend.
- Two endings. Find all 23 notes for the full story.

Estimated play time: 20-30 minutes.
